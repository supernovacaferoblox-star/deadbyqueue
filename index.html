Privacy Policy

Effective Date: September 3, 2026

This Privacy Policy explains how the Dead by Queue Discord Bot ("the Bot", "we", "us") handles user data when added to Discord servers or used by Discord accounts.

1. Information We Collect

We believe in minimal data collection. When you interact with the Bot via slash commands (e.g., /queue), the following temporary data is processed in real-time:

  • Command Interactions: Discord User IDs and Guild (Server) IDs required by Discord's API to process and respond to interactions.
  • Selected Command Options: The region parameter selected during command execution.

2. Information We DO NOT Collect or Store

  • We do not store persistent user data in any external database.
  • We do not store message content or track chat histories.
  • We do not collect personal identifiable information (PII) such as real names, email addresses, or payment information.

3. How Data Is Used

Processed data is used solely for the purpose of executing requested slash commands (fetching queue times from deadbyqueue.com) and returning formatted embeds to your Discord channel.

4. Third-Party Services

The Bot fetches publicly available queue duration estimates from deadbyqueue.com. No Discord user data is transmitted to deadbyqueue.com during these requests.

5. Data Retention & Deletion

Because no user data or command history is permanently stored in a database, there is no stored personal data to retain or delete. All interaction tokens expire automatically per Discord's standard API rules.
